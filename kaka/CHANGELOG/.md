# История изменений (Changelog)

All notable changes to this project will be documented in this file.

---

## [v2.7.2] - 2026-08-11 - [Hotfix]
### Fixed
- **Исправление импорта Vite**: Удалены проблемные внешние библиотеки `html-to-image` и `html2canvas`, вызывавшие ошибку модуля Vite на Windows и локальных серверах (`Failed to resolve import "html-to-image"`).
- **Синхронизация PNG-экспорта**: Переписан экспортер изображений на автономный HTML5 2D Canvas. Скачиваемая картинка в Full HD на 100% совпадает с экраном предпросмотра.

---

## [v2.7.1] - 2026-08-11 - [Update]
### Added
- **Драматичная анимация 12 баллов (Евровидение)**: Внедрен 5-фазный порядок начисления очков (Исходный скорборд -> Поочередные обычные баллы -> Драматичная пауза -> Раскрытие 12 баллов -> Скольжение плашек).
- **Спецэффекты для максимального балла**: Добавлено золотое свечение карт, плашка `👑 +MAX` и сияющие искры.

---

## [v2.7.0] - 2026-08-10 - [Release]
### Added
- **Генератор Скорборда 2.7.0 PRO VIDEO**: Видео-экспорт (MP4/WebM), адаптивные стили (Евровидение, Стаявидение, Сплитскрин), нижняя плашка голосования жюри и кастомизация.
